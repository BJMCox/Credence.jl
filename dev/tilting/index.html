Updating a reference prior

Bounded-KL tilting adjusts a fixed reference prior to satisfy further probability or expectation requirements. It minimizes D(Q || P) subject to those requirements and explicit bounds on the density ratio dQ/dP. The reference remains fixed throughout the fit.

Probability requirements

Consider a standard Normal reference for a standardized calibration offset. The expert requires a probability between 0.68 and 0.72 that the offset is positive:

using Credence, MeasureBase, Randomreference = StdNormal()beliefs = (Hard(:positive, Probability(0, Inf), Between(0.68, 0.72)),)method = BoundedKL(lower=0.5, upper=2.0)report = tilt(reference, beliefs, method)checks = validate(Xoshiro(701), report)selection =    select(report; validation=checks, rationale="Positive-offset probability reviewed")prior = measure(selection)(    probability=evaluate(Probability(0, Inf), prior).value,    logdensity=logdensityof(prior, 1.0),)
(probability = 0.68, logdensity = -1.111453833456712)

The optimum assigns probability 0.68 to the positive half-line. Its density ratio is constant within the event and its complement. Their reference probabilities determine the two constants analytically. rand(Xoshiro(702), prior^4096) draws independently from the updated law through bounded rejection.

The lower ratio bound preserves the reference's positive-mass regions. A zero lower bound permits boundary solutions, including conditioning on an event. Both the event and its complement constrain the feasible probability range.

Joint probability requirements

Suppose two standardized calibration errors start as independent standard Normals. Each is positive half the time, so both are positive in one quarter of draws. The expert expects both errors to be positive together 40% to 45% of the time.

using Credence, MeasureBase, Randomreference = productmeasure((gain=StdNormal(), offset=StdNormal()))both_positive = Probability(gain=(0, Inf), offset=(0, Inf))beliefs = (Hard(:both_positive, both_positive, Between(0.4, 0.45)),)report = tilt(reference, beliefs, BoundedKL(lower=0.5, upper=2))checks = validate(Xoshiro(704), report)choice = select(report; validation=checks, rationale="Reviewed joint calibration")prior = measure(choice)(    both_positive=evaluate(both_positive, prior).value,    gain_positive=evaluate(Probability(gain=(0, Inf)), prior).value,    offset_positive=evaluate(Probability(offset=(0, Inf)), prior).value,)
(both_positive = 0.4, gain_positive = 0.6, offset_positive = 0.6)

The prior closest to the reference in KL divergence assigns 40% probability to the event. It multiplies the reference density by 1.6 inside the event and 0.8 outside. Each parameter now has a 60% chance of being positive. This joint update changes the marginals as well as their dependence.

Each named interval uses lower < value <= upper. Leave a parameter out to let it take any value. The reference must be an independent product with scalar interval probabilities. A single joint probability update uses the analytic solution above.

Use the resulting named prior directly in Wren when both cells retain positive mass. The density jumps at the event boundary, so check sampler behavior near either threshold if you use gradient-based inference. The same save_session and flatppl calls below also work for this prior.

Keep the marginal laws fixed

Suppose separate calibration results already determine both marginal laws. A new joint probability can change their dependence while keeping both laws fixed. Use preserve_marginals=true with one belief that names a pair of parameters in an independent product. All other factors remain independent of the pair.

beliefs = (Hard(:both_positive, both_positive, Between(0.36, 0.37)),)fixed = tilt(reference, beliefs, BoundedKL(lower=0.5, upper=2); preserve_marginals=true)fixed_prior = measure(fixed)(    both_positive=evaluate(both_positive, fixed_prior).value,    gain_positive=evaluate(Probability(gain=(0, Inf)), fixed_prior).value,    offset_positive=evaluate(Probability(offset=(0, Inf)), fixed_prior).value,)
(both_positive = 0.36, gain_positive = 0.5, offset_positive = 0.5)

The two intervals divide the reference into four cells. The update adds the same mass to the two matching cells and removes it from the two mixed cells. The table's row and column totals stay fixed. Independence in the reference and constant weights within each cell preserve each full marginal law.

The ratio bounds and fixed marginals restrict the joint probability to 0.125–0.375 in this example. An infeasible belief raises an error with the attainable range. Draw a batch with rand(Xoshiro(705), fixed_prior^32). The updated prior supports saved sessions and FlatPPL export.

Moment requirements

General requirements use an Optimization.jl algorithm. The dual objective supplies analytic gradients. A Uniform reference below explicitly assumes equal density on the unit interval:

using Optimization, OptimizationOptimJLmoment_report = tilt(    StdUniform(),    (Hard(:mean, Mean(), Between(0.55, 0.6)),),    method,    Fminbox(BFGS());    g_tol=1e-10,)(    mean=evaluate(Mean(), measure(moment_report)).value,    feasibility=moment_report.feasibility,    optimality=moment_report.optimality,)
(mean = 0.5500000002070793, feasibility = :feasible, optimality = :numerical)

Mean() and Probability(...) describe linear expectations. Expectation(f) applies a pointwise function before averaging. Its absolute reference expectation must exist. Statistic(f) instead receives a measure and retains its separate family-fitting meaning. Scalar continuous integration requires an atom-free reference with an SMF and inverse. Known interval boundaries split the integration domain. Quadrature sets the error target and evaluation budget over the full reference probability range.

For an actual finite law, declare its support and relative masses with FiniteReference((0.0, 1.0, 2.0), (1, 2, 1)). Use IPNewton() for its constrained primal problem. The finite solver supplies objective and constraint derivatives and checks the original requirements after solving.

Finite constraints can force atoms to zero mass or to a ratio cap. The solver removes coordinates proved fixed by an extremal requirement before optimizing the remaining masses. Other boundary faces can leave optimality unresolved. The report distinguishes these cases from a proved infeasible requirement.

Using the updated prior

The selected measure supports ordinary MeasureBase density evaluation and sampling. Its Plaice chart uses the reference support. Conditioning on a connected interval restricts that chart to the retained interval. A disconnected support requires a separate chart; finite laws have no continuous chart.

The Wren integration example accepts such a measure as its prior. For example, the selected Normal event tilt above can be used directly:

using Wren: @wren, VecModel, FromPriorusing ADTypes: AutoForwardDiffusing LogDensityProblems: logdensity_and_gradient@wren function calibration_offset(prior)    offset ~ priorendmodel = VecModel(    calibration_offset(prior),    AutoForwardDiff();    latent_source=FromPrior(Xoshiro(703)),)logdensity_and_gradient(model, [0.4])

Saved sessions

Each selection retains its TiltReport, including the reference, normalization, KL divergence, ratio bounds, and projection status. Save the selection with its validation and rationale, then reload the fitted state:

restored = mktempdir() do directory    path = joinpath(directory, "calibration-prior.toml")    save_session(path, selection; metadata=(parameter=:offset,))    load_session(path)endrestored_selection = only(restored.selections)(    role=restored_selection.role,    normalization=restored.report.normalization,    logdensity=logdensityof(measure(restored_selection), 1.0),)
(role = :accepted, normalization = Estimate{Float64, Float64, Float64}(1.0, 1.0, 1.0, :analytic, 0), logdensity = -1.111453833456712)

Loading restores the fitted parameters and retained checks. Numerical normalization estimates keep their bounds and evidence. Custom expectation functions use the same versioned callback registry for saving and loading, as in other saved sessions.

Pass measure(restored_selection) as the prior in the Wren model above. FlatPPL export preserves the restored event weights and known normalizer:

flatppl(restored_selection)
"weighted(\n    1.0,\n    weighted(\n        x -> ifelse((0 < x) && (x <= inf), 1.36, 0.6399999999999999),\n        Normal(0.0, 1.0)\n    )\n)"

Finite laws export as weighted atoms. Affine tilts of StdUniform() export as clipped exponential weights. Arbitrary Julia callbacks require a FlatPPL translator.

Numerical evidence

The report separates solver results, feasibility, optimality, normalization, and density ratio bounds. :within_tolerance identifies a numerical constraint residual. validate(rng, report) supplies fresh belief checks. Acceptance requires resolved projection evidence and the ordinary validation checks.

Analytic event updates and affine tilts of StdUniform() have known normalizers. General scalar tilts retain a quadrature estimate separately from their native measure. For these fits, logdensity_estimate(report, x) returns an Estimate with estimated normalization error. Ordinary normalized logdensityof remains unavailable while the normalizer is unknown. Independent rejection draws still target the normalized law.

If the fitted raw weight is w and its mass is Z, the sampled density ratio is w/Z. The reported ratio bounds propagate the normalization error. Estimated evidence therefore remains separate from a claim that the original ratio bounds hold exactly. A nonconverged solver leaves optimality unresolved. An exhausted quadrature budget raises an error so the integration settings can be revised.

A numerical fit can be retained with select(report; role=:reference, validation, rationale="..."). For posterior inference with this fitted prior held fixed, MeasureBase.basemeasure(measure(report)) supplies the native unnormalized kernel. Its missing normalizer is constant across parameter points. Normalized density evaluation and marginal likelihoods require the normalization evidence separately.
