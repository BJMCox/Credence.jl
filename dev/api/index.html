Credence.DirichletLaplaceFamily — Type
DirichletLaplaceFamily(n; concentration=1/n, scale=nothing, starts=nothing)

Construct the Dirichlet–Laplace hierarchy with per-component concentration a, allocation ϕ ~ Dirichlet(fill(a, n)), and global_scale ~ Gamma(n*a, 2) in shape-scale form. Conditional coefficient scales are scale * global_scale * ϕ. The output retains coefficients, global_scale, and allocation.

Set concentration or scale to nothing to fit it, using log_concentration or log_scale in starts. Integrating both auxiliary variables gives independent Gamma-mixture Laplace coefficients. The default concentration is 1/n.

Credence.FunctionalHorseshoeFamily — Type
FunctionalHorseshoeFamily(design, baseline; baseline_scale, scale=nothing,
                         a=0.5, b=0.5, starts=nothing)

Shrink a function design * coefficients towards the column space of baseline. The design must have full column rank and contain the baseline subspace. Redundant baseline columns are allowed. At least one direction must lie outside the baseline. The output retains coefficients and shrinkage.

The shrinkage weight follows Beta(a, b) and gives tau = sqrt((1 - shrinkage) / shrinkage). Conditional deviations have scale scale * tau in an orthonormal observation-space basis. Set scale=nothing to fit it, using log_scale in starts.

baseline_scale sets a proper zero-mean Gaussian law on the baseline projection, in observation-space units. This completes the improper baseline directions in Shin, Bhattacharya, and Johnson's functional horseshoe prior (equations 4–5). Treat the stored design, baseline, and cached geometry arrays as read-only. Construct a new family when changing its geometry.

Credence.GeneralizedDoubleParetoFamily — Type
GeneralizedDoubleParetoFamily(dimension; shape=1.0, scale=nothing, starts=nothing)

Construct a generalized double Pareto prior with marginal density (1 + abs(x)/(shape*scale))^(-shape-1) / (2scale) for each coefficient. Here scale is the paper's ξ and shape is its α. The mean exists for shape > 1, and the variance is 2(shape*scale)^2 / ((shape-1)*(shape-2)) for shape > 2. Use quantiles or event probabilities for heavier tails.

Independent unit-scale Laplace draws divided by independent unit-rate Gamma variables give the coefficient mixture. The joint record retains coefficients and local_rates. Physical conditional Laplace rates are local_rates / (shape*scale). Numeric keywords fix hyperparameters; nothing fits log_shape or log_scale through starts.

source
Credence.GroupHorseshoeFamily — Type
GroupHorseshoeFamily(groups; scale=nothing, starts=nothing)

Define one group label per coefficient. Independent unit half-Cauchy global, group, and local scales give conditional coefficient standard deviations scale * global_scale * group_scales[group] * local_scales. scale fixes the global scale multiplier; nothing fits log_scale. The joint measure retains coefficients, global_scale, group_scales, and local_scales. Group scales follow label order of first appearance.

This is the one-level grouped global-local horseshoe of Xu et al. (2017), Section 2.3. A singleton group still has both a group scale and a local scale.

Credence.MultiplicativeGammaFamily — Type
MultiplicativeGammaFamily(rows, columns; first_shape=2.0, later_shape=3.0,
                          local_df=3.0, scale=nothing, starts=nothing)

Construct a finite multiplicative Gamma hierarchy for a loading matrix. Local precisions have shape-rate parameters local_df/2, local_df/2. Independent Gamma increments have unit rate, with shape first_shape for the first column and later_shape for later columns. Their cumulative products form column precisions. Conditional loading variances are scale^2 / (local_precision * column_precision). The output retains coefficients, local_precisions, and increments.

Set a parameter to nothing to fit it through its log_ starting coordinate. All finite positive shapes define a proper finite prior. Expected loading variances decrease across columns when local_df > 2, first_shape > 1, and later_shape > 2. Individual increments can be below one, so shrinkage varies between draws.

Credence.NormalGammaFamily — Type
NormalGammaFamily(dimension; shape=nothing, scale=nothing, starts=nothing)

Construct the Normal–Gamma variance-mixture prior of Griffin and Brown (2010). Each coefficient has conditional law Normal(0, sqrt(local_variance)), with independent local_variance ~ Gamma(shape, 2 * scale^2) in shape-scale form. The marginal variance is 2 * shape * scale^2 and excess kurtosis is 3 / shape. At shape=1, the coefficient marginal is Laplace(0, scale).

Numeric keyword values fix the parameters. Set either to nothing to fit it through log_shape or log_scale. Draws retain coefficients and local_variances in one joint record.

Credence.Predictive — Type
Predictive(name, references, kernel)
Predictive(name, references; simulator)

Define an observable whose conditional measure is kernel(parameters...), with parameters passed in reference order. The kernel must return a normalized MeasureBase measure. Sampled evaluation draws one observation per shared prior draw and reuses that observation across beliefs about this predictive target. Alternatively, simulator(rng, parameters...) returns an observation directly. Each joint prior/observation draw contributes one sample to the uncertainty estimate.

Credence.R2D2Family — Type
R2D2Family(dimension; noise_scale, predictor_scales, mean_r2=nothing,
           precision_r2=nothing, concentration=1/dimension, starts=nothing)

Fit the marginal R2-D2 prior for Gaussian linear regression. Predictors are centered, predictor_scales gives their standard deviations, and noise_scale is the residual standard deviation. Both must be supplied in the model's units.

The variance budget r2 has a Beta law with shapes mean_r2 * precision_r2 and (1 - mean_r2) * precision_r2. A symmetric Dirichlet with per-component concentration allocates that budget. Conditional coefficients are Laplace with scales noise_scale * sqrt.(allocation * r2 / (2 * (1-r2))) ./ predictor_scales. Here r2 describes the prior variance budget after averaging over coefficients and predictors. It differs from a realized coefficient vector's explained variance.

Fixed keyword values remove fitting coordinates. Free mean_r2 uses logit_mean_r2; free positive parameters use log_precision_r2 and log_concentration. The measure returns a record with coefficients, r2, and allocation.

Credence.RegularizedHorseshoeFamily — Type
RegularizedHorseshoeFamily(dimension; scale=nothing, slab_scale=nothing,
                         slab_df=4.0, starts=nothing)

Fit a regularized horseshoe prior. The slab variance is slab_scale^2 * slab_aux, where slab_aux has an inverse-Gamma law with shape and scale slab_df / 2. Numeric scale and slab_scale values fix these parameters; nothing fits them through log_scale and log_slab_scale. slab_df is fixed. Draws retain the coefficients and their positive auxiliary scales in one joint record.

Credence.load_session — Method

Restore a saved session as a named record with problem, report, validation, selections, history, metadata, and environment. Measures are rebuilt from saved parameters without optimization. Credence.save_session — Method
save_session(path, problem; report=nothing, validation=nothing,
             selections=(), history=(), metadata=(;), callbacks=(;))

Save judgments, family definitions, fitted parameters, validation, and selection rationales as versioned TOML. History can contain earlier problems and plain records. Register custom builders and statistical, derived, or predictive callbacks under stable names. Entries can be functions or (callback=f, version="1") records. Source-backed callbacks record source and capture fingerprints. REPL callbacks and opaque captures require an explicit version. Loading verifies fingerprints before restoring validation. Direct global data is fingerprinted too. Versions are the caller's reconstruction contract for transitive helpers and opaque state, which cannot be checked automatically.
