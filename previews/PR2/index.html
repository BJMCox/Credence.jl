Credence.jl

Credence turns an expert's beliefs into candidate prior distributions. State probability, quantile, mean, or spread beliefs, compare several families, then select a prior explicitly. The result is a native MeasureBase measure that can enter a Wren model.

This is an initial prototype for a single expert. Candidate comparison supports expert judgment. It does not choose a family for you.

Installation

Credence is not registered. From a source checkout, install its pinned development dependencies:

git clone https://github.com/BJMCox/Credence.jl.git
cd Credence.jl
julia --project=. dev/setup.jl

The core supports Julia 1.10 and later. Use Julia 1.13 or later for the example environments, which use Pkg's source pins for the development MeasureBase and Wren APIs.

Check a belief

Suppose the prior's median should lie between -0.1 and 0.1. Compare a standard Normal and a standard Exponential distribution at their declared parameter points:

using Credence, MeasureBase, Randombelief = Hard(:median, Quantile(0.5), Between(-0.1, 0.1))candidates = (    Candidate(:normal, _ -> StdNormal(), [0.0]),    Candidate(:exponential, _ -> StdExponential(), [0.0]),)problem = Elicitation((belief,), candidates)report = fit(Xoshiro(1), problem)validation = validate(Xoshiro(2), report)map(validation.checks) do checks    check = only(checks)    (; median=check.estimate.value, status=check.status)end
((median = -0.0, status = :satisfied), (median = 0.6931471805599453, status = :violated))

fit(rng, problem) evaluates the supplied points. It does not optimize them. The Normal median satisfies the requirement. The Exponential median does not.

Select and use a prior

Selection records your rationale and retains the validation that supports acceptance:

selection = select(    report,    (:normal, 1);    validation,    rationale="The median satisfies the expert's stated range.",)prior = measure(selection)rand(Xoshiro(3), prior^5)
5-element Vector{Float64}:
 -0.6637635515551271
  1.3632084599735597
  0.7174105899241786
  0.6787430624233933
  1.5324588165455708

measure(selection) returns the selected measure itself. The report stays separate from the prior. Treat report measures and captured callbacks as read-only after validation.

Fit and compare families

Loading Optimization.jl adds fit(rng, problem, algorithm; ...). The family comparison tutorial fits Normal and Student-t candidates to the same quartiles and examines their different tails.

The Wren tutorial fits a joint coefficient and scale prior, preserves coefficient dependence through Plaice, then samples a posterior with NUTS.

Beliefs and validation explains hard requirements, approximate targets, numerical evidence, and acceptance. The API reference lists the available constructors and operations.

Predictive fitting, formula macros, tilting, marginal locks, judgment-uncertainty propagation, portable persistence, interactive controls, and FlatPPL export remain planned.

Between(lower, upper)

Require a statistic to lie in the closed interval [lower, upper].

Candidate(id, build, starts; lower=nothing, upper=nothing)

A MeasureBase family builder with explicit starts and optional parameter bounds.

Elicitation(beliefs, candidates)

An immutable collection of beliefs and candidate definitions.

Hard(id, statistic, relation)

A named hard requirement on a statistic.

Quantile(p)

The lower quantile at probability p, with 0 < p < 1.

measure(selection)

Return the selected native MeasureBase measure, separate from its fitting report.

select(report, result_id; role=:accepted, validation=nothing, rationale)

Select one concrete result as a reference or accepted prior, preserving its validation.

validate(rng, report; plan=Analytic())

Reevaluate fixed results.

fit(rng, problem; plan=Evaluate())

Evaluate declared parameter points, or fit through an optional optimizer extension.
