Credence.jl

Prior elicitation expresses expert knowledge as a probability distribution. Credence fits several distribution families to judgments about probabilities, quantiles, means, and standard deviations. The expert reviews their agreement with those judgments and selects a prior, recording the reason for the choice.

The package supports a single expert. Priors use MeasureBase and can enter Wren models through Plaice.

Installation

Install Credence from the Julia REPL with Julia 1.13.

using PkgPkg.add(url="https://github.com/BJMCox/Credence.jl.git")

A first example

Add Distributions to use the built-in distribution families.

Pkg.add("Distributions")

Suppose the prior median of x must lie between -0.1 and 0.1. Represent this requirement with Hard and compare standard Normal and Exponential priors.

using Credence, Distributions, Randombeliefs = (:x => (Hard(:median, Quantile(0.5), Between(-0.1, 0.1)),),)candidates = (    :x => (        :normal => NormalFamily(location=0.0, scale=1.0),        :exponential => ExponentialFamily(scale=1.0),    ),)problem = Elicitation(beliefs, candidates)report = fit(Xoshiro(1), problem)validation = validate(Xoshiro(2), report)validation

fit evaluates each candidate at its declared parameters. The Normal median is 0 and satisfies the requirement. The Exponential median is log(2) and falls outside the interval.

After reviewing these checks, select the Normal result and record the reason:

selection = select(    report,    :x,    (:normal, 1);    validation,    rationale="The median satisfies the expert's stated range.",)prior = measure(selection)rand(Xoshiro(3), prior^5)

measure(selection) returns the prior as a MeasureBase measure. The fitting report and validation remain available separately. Treat the measures and callbacks in a validated report as read-only, so that the validation continues to describe the selected prior.

For numerical fitting, load Optimization.jl and call fit(rng, problem, algorithm; ...).

Examples and guides

Each example starts with its own judgments and candidate priors. Run the Julia scripts from the package directory with Julia 1.13 or later. Wren uses the environment listed on its example page.

julia --project=examples -e 'using Pkg; Pkg.instantiate()'
julia --project=examples examples/pump_repair.jl
LevelExamples
EasyCheck a calibration tolerance and fit two families to repair times.
IntermediateRevise and save a monitor calibration and fit a vector of source fractions.
AdvancedCheck prior predictions for a rare-event search and sample a posterior in Wren.
Very advancedCompare compound shrinkage priors and export a complete FlatPPL model.

Named inputs describes parameter references, arrays, and joint beliefs. Beliefs and validation defines the fitting objective, candidate comparisons, and the evidence required for acceptance. Tilting an existing prior covers further probability or expectation requirements for a fixed reference. The API reference documents the constructors and methods.

Between(lower, upper)

Require a statistic to lie in the closed interval [lower, upper].

Elicitation(beliefs, candidates)

An immutable collection of beliefs and candidate definitions.

ExponentialFamily()

ExponentialFamily(; scale=nothing, starts=nothing) fits an Exponential prior with mean scale.

Hard(id, statistic, relation)

A named hard requirement on a statistic.

NormalFamily

NormalFamily(; location=nothing, scale=nothing, starts=nothing) fits a Normal law with optional fixed location or scale.

Quantile(p)

The lower quantile at probability p, with 0 < p < 1.

measure(selection)

Return the selected native MeasureBase measure, separate from its fitting report.

select(report, result_id; role=:accepted, validation=nothing, rationale)

Select one concrete result as a reference or accepted prior, preserving its validation.

validate(rng, report; plan=Analytic(), sampling=report.sampling)

Reevaluate fixed results with fresh draws.

fit(rng, problem; plan=Evaluate())

Evaluate declared parameter points, or fit through an optional optimizer extension.
