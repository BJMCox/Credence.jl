Compare shrinkage priors for building load

A building-load model uses two weather predictors and two occupancy predictors. Predictors and load are standardized. The expert expects modest load variation for a specified operating condition and allows for occasional large coefficients.

using Credence, Distributions, MeasureBase, Randomgroups = (:weather, :weather, :occupancy, :occupancy)candidates = (    :effects => (        :regularized =>            RegularizedHorseshoeFamily(4; scale=0.12, slab_scale=0.7, slab_df=4),        :grouped => GroupHorseshoeFamily(groups; scale=0.08),    ),)
(:effects => (:regularized => RegularizedHorseshoeFamily{Float64, Float64, Int64, Nothing}(4, 0.12, 0.7, 4, nothing), :grouped => GroupHorseshoeFamily{NTuple{4, Symbol}, NTuple{4, Int64}, Float64, Nothing}((:weather, :weather, :occupancy, :occupancy), (1, 1, 2, 2), 0.08, nothing)),)

The first prior limits the spread of large coefficients through a slab. The second shares a shrinkage scale within each predictor group. Both return a record of coefficients and latent scales.

Assess the largest absolute coefficient and the predicted load at one set of predictor values. The observation model has a fixed residual deviation of 0.25.

predictors = (1.0, 0.5, -0.5, 0.75)function observation(effects)    location = sum(effects.coefficients .* predictors)    return asmeasure(Normal(location, 0.25))endlargest_effect =    Derived(:largest_effect, :effects, effects -> maximum(abs, effects.coefficients))future_load = Predictive(:future_load, :effects, observation)beliefs = (    largest_effect =>        (Approximate(:large_effect, Probability(1, Inf), 0.15; scale=0.08),),    future_load => (        Hard(:load_band, Probability(-2, 2), AtLeast(0.85)),        Approximate(:central_load, Probability(-0.7, 0.7), 0.75; scale=0.08),    ),)

Select the regularized prior after checking its predictions. Draw the coefficients and their scales together, then draw a load given those values.

Approximate(id, statistic, target; scale, importance=1)

An approximate point target with an explicit scale and optional importance weight.

AtLeast(value)

Require a statistic to be at least the stated value.

Derived

Derived(name, references, f) calls f with the selected values in order.

Elicitation(beliefs, candidates)

An immutable collection of beliefs and candidate definitions.

GroupHorseshoeFamily(groups; scale=nothing, starts=nothing)

Define one group label per coefficient.

Hard(id, statistic, relation)

A named hard requirement on a statistic.

MonteCarlo(n; alpha=0.01)

Evaluate statistics from n independent draws with numerical uncertainty at level alpha.

Predictive(name, references, kernel) Predictive(name, references; simulator)

Define an observable whose conditional measure is kernel(parameters...), with parameters passed in reference order.

Probability(a, b) Probability(predicate) Probability(; parameter=(a, b), ...)

The probability P(a < X <= b), or an event defined by a predicate.

RegularizedHorseshoeFamily(dimension; scale=nothing, slab_scale=nothing, slab_df=4.0, starts=nothing)

Fit a regularized horseshoe prior.

belief_summary(validation; result_id=nothing)

Return one named row per retained belief check.

measure(selection)

Return the selected native MeasureBase measure, separate from its fitting report.

select(report, result_id; role=:accepted, validation=nothing, rationale)

Select one concrete result as a reference or accepted prior, preserving its validation.

validate(rng, report; plan=Analytic(), sampling=report.sampling)

Reevaluate fixed results with fresh draws.

fit(rng, problem; plan=Evaluate())

Evaluate declared parameter points, or fit through an optional optimizer extension.
