Revise and save a calibration prior

An air-quality monitor has a positive response lag in seconds and a signed concentration offset in μg/m³. Calibration staff specify tolerance requirements and estimate a mean and standard deviation for each parameter.

using Credence, Distributions, MeasureBase, Optimization, OptimizationOptimJL, Randomimport ForwardDiffbeliefs = (    :lag => (        Hard(:responds_by_25s, Probability(0, 25), AtLeast(0.95)),        Hard(:takes_over_3s, Probability(3, Inf), AtLeast(0.95)),        Approximate(:mean, Mean(), 10.0; scale=2.0),        Approximate(:spread, Std(), 4.0; scale=1.0),    ),    :offset => (        Hard(:mean_bias, Mean(), Between(-0.5, 0.5)),        Hard(:within_3, Probability(-3, 3), AtLeast(0.95)),        Approximate(:mean, Mean(), -0.2; scale=0.15),        Approximate(:spread, Std(), 1.1; scale=0.25),    ),)candidates = (    :lag => (        :lognormal => LogNormalFamily(starts=(location=log(9.0), log_scale=log(0.4))),        :gamma => GammaFamily(starts=(log_shape=log(6.0), log_scale=log(1.7))),    ),    :offset => (:normal => NormalFamily(starts=(location=-0.2, log_scale=0.0)),),)problem = Elicitation(    beliefs,    candidates;    combinations=(        :lognormal_lag => Independent(:lag=>:lognormal, :offset=>:normal),        :gamma_lag => Independent(:lag=>:gamma, :offset=>:normal),    ),)
Elicitation(8 beliefs, 2 candidates)

Approximate(id, statistic, target; scale, importance=1)

An approximate point target with an explicit scale and optional importance weight.

AtLeast(value)

Require a statistic to be at least the stated value.

Between(lower, upper)

Require a statistic to lie in the closed interval [lower, upper].

Elicitation(beliefs, candidates)

An immutable collection of beliefs and candidate definitions.

GammaFamily()

GammaFamily(; shape=nothing, scale=nothing, starts=nothing) fits a shape-scale Gamma prior.

Hard(id, statistic, relation)

A named hard requirement on a statistic.

Independent

Independent(reference => family_id, ...) declares one independent combination.

LogNormalFamily

LogNormalFamily(; location=nothing, scale=nothing, starts=nothing) fits a LogNormal law with optional fixed log location or log standard deviation.

Mean()

The population mean, when it exists.

NormalFamily

NormalFamily(; location=nothing, scale=nothing, starts=nothing) fits a Normal law with optional fixed location or scale.

Probability(a, b) Probability(predicate) Probability(; parameter=(a, b), ...)

The probability P(a < X <= b), or an event defined by a predicate.

Std()

The population standard deviation, when it exists.

belief_summary(validation; result_id=nothing)

Return one named row per retained belief check.

compare(report; validation=nothing) compare(rng, report; plan=Analytic(), sampling=report.sampling)

Compare feasible results using simultaneous discrepancy bounds.

load_session(path; callbacks=(;))

Restore a saved session as a named record with problem, report, validation, selections, history, metadata, and environment.

measure(selection)

Return the selected native MeasureBase measure, separate from its fitting report.

save_session(path, problem; report=nothing, validation=nothing, selections=(), history=(), metadata=(;), callbacks=(;))

Save judgments, family definitions, fitted parameters, validation, and selection rationales as versioned TOML.

save_session(path, report::TiltReport; validation=nothing, selections=(), kwargs...) save_session(path, selection; kwargs...)

Save a fitted projection or a selected prior with its report and validation.

select(report, result_id; role=:accepted, validation=nothing, rationale)

Select one concrete result as a reference or accepted prior, preserving its validation.

validate(rng, report; plan=Analytic(), sampling=report.sampling)

Reevaluate fixed results with fresh draws.

fit(rng, problem; plan=Evaluate())

Evaluate declared parameter points, or fit through an optional optimizer extension.
